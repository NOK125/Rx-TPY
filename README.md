# Rx-TPY — ระบบบันทึกงานบริการเภสัชกรรม โรงพยาบาลตาพระยา

เว็บสำหรับเภสัชกรบันทึกและสรุปงานบริการเภสัชกรรม ใช้ภายในวงแลนของโรงพยาบาล ไม่ต้องใช้อินเทอร์เน็ต

## งานในระบบ

| กลุ่ม | งาน |
|---|---|
| ความปลอดภัยด้านยา | แพ้ยา / ADR · ผลการรายงานความเสี่ยง (Risk Management) · รายงานผลการตรวจใบสั่งยานอกเวลาราชการ |
| งานบริการผู้ป่วย | ให้คำปรึกษาด้านยา · Med reconciliation |
| คลินิก | คลินิกวาร์ฟาริน · คลินิก COPD · คลินิก DM |
| งานบริหาร | ตรวจสอบ STOCK หน่วยบริการ · งานจัดซื้อ · ตารางเวร (ปฏิทินรายเดือน) |

**รายงานผลการตรวจใบสั่งยานอกเวลาราชการ** มีหน้าวิเคราะห์ของตัวเอง: ร้อยละความคลาดเคลื่อนรายเดือน แยกตามเวรและ OPD/IPD
ประเภท DRP ยาที่เกิด DRP บ่อย และสรุปตามผู้คัดกรอง เลือกดูทั้งหมด รายปีงบประมาณ หรือรายเดือน
**ดาวน์โหลด Excel** (ชีตข้อมูล + ชีตสรุป) และ **PDF** (ผ่านหน้าต่างพิมพ์ → บันทึกเป็น PDF) ตามช่วงเวลาที่เลือก และ**นำเข้าจาก Excel** ได้ (ปุ่ม "นำเข้า Excel"): ไฟล์ .xlsx หลายชีต แต่ละชีตมีหัวตาราง "วัน เดือน ปี | เวร | OPD/IPD |
จำนวนที่คัดกรอง | จำนวนที่คลาดเคลื่อน | ร้อยละ | DRP ที่ตรวจพบ | ยาที่เกิด DRP | หมายเหตุ | ผู้คัดกรอง"
ระบบแก้ปีที่พิมพ์เป็น พ.ศ. ใน Excel ให้อัตโนมัติจากชื่อชีต (เช่น "ก.ค. 68") และข้ามแถวที่เคยนำเข้าแล้ว จึงนำเข้าไฟล์เดิมซ้ำได้

ความสามารถที่ใช้ร่วมกันทุกงาน
- เลือกดูรายเดือน ค้นหา และดูสรุปจำนวนและสัดส่วนของแต่ละหัวข้อ
- ส่งออก CSV (เปิดใน Excel ภาษาไทยได้) และพิมพ์บันทึกรายฉบับ
- **ค้นหาผู้ป่วยด้วย HN** เพื่อดูบันทึกทุกงาน และเตือนเมื่อมีประวัติแพ้ยา / ADR ทั้งตอนค้นหาและตอนบันทึกงานอื่น
- หน้าแรกแสดงยอดเดือนนี้ เวรวันนี้ และนัดคลินิก (ขาดนัด / ใกล้ถึง)
- เก็บประวัติการแก้ไขทุกครั้ง การลบเป็นแบบซ่อน (ข้อมูลเดิมยังอยู่)

## ใช้งานจริงบน Cloudflare (https://rx.tpy-inventory.com)

ระบบจริงรันบน Cloudflare Workers + ฐานข้อมูล D1 ไม่ต้องเปิดเครื่องใดทิ้งไว้ Cloudflare ดึงโค้ดจาก GitHub ไป deploy เองทุกครั้งที่ push

ติดตั้งครั้งแรก (ทำใน Cloudflare dashboard ตามลำดับ)
1. **D1:** Storage & Databases → D1 → Create database ชื่อ `rx-tpy` แล้วคัดลอก Database ID ไปใส่ใน `wrangler.jsonc`
2. **Cloudflare Access (ทำก่อนเปิดเว็บครั้งแรก):** Zero Trust → Access → Applications → Add an application → Self-hosted → โดเมน `rx.tpy-inventory.com` → Policy: Allow เฉพาะอีเมลของเภสัชกร
3. **Worker:** Workers & Pages → Create → Import a repository → เลือก repo นี้ → Deploy command `npx wrangler deploy` → Deploy (ระบบสร้าง rx.tpy-inventory.com ให้เอง)
4. เปิด https://rx.tpy-inventory.com แล้วสร้างบัญชีผู้ดูแลระบบคนแรก

สำรองข้อมูล: D1 มี Time Travel ย้อนข้อมูลได้ 30 วัน หรือส่งออกเป็นไฟล์ได้จากหน้า D1 ใน dashboard

## รันในเครื่อง (ไม่ใช้อินเทอร์เน็ต)

ต้องใช้ Python 3.10 ขึ้นไป ไม่ต้องติดตั้งไลบรารีเพิ่ม ฐานข้อมูลแยกจากบน Cloudflare

- Windows: ดับเบิลคลิก `run.bat`
- หรือรัน `python server.py --open` แล้วเปิด http://127.0.0.1:8100

ครั้งแรกระบบจะให้สร้างบัญชีผู้ดูแลระบบ แล้วจึงเพิ่มบัญชีเภสัชกรในเมนู "ผู้ใช้"

## สิทธิ์

- **เภสัชกร** บันทึกและดูได้ทุกงาน แก้ไขได้เฉพาะบันทึกของตัวเอง
- **ผู้ดูแลระบบ** แก้ไขและลบได้ทุกบันทึก และจัดการผู้ใช้

## ตั้งค่า

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `8100` | พอร์ต |
| `HOST` | `127.0.0.1` | ใช้ `0.0.0.0` ถ้าต้องการให้เครื่องอื่นในวงแลนเข้าได้ |
| `RX_DB` | `data/rx.db` | ไฟล์ฐานข้อมูล SQLite |

โฟลเดอร์ `data/` มีข้อมูลผู้ป่วย ไม่ขึ้น Git ให้สำรองไฟล์ `data/rx.db` เป็นประจำ
